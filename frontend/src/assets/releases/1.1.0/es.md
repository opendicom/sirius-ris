# Frontend 1.1.0 | Backend 1.1.0 | Database 1.1.0

## Detalles de la versión

- Se utiliza `opendicom_sirius_database` (imagen de base de datos personalizada basada en MongoDB oficial).
- Sistema de restauración de la base de datos incluido en la imagen `opendicom_sirius_database`.
- Sistema de ejecución de tareas programadas mediante cron.
- Sistema de respaldo automático con políticas de control de retención para volcados (dumps) y registros (logs).
