# Frontend 1.1.0 | Backend 1.1.0 | Database 1.1.0

## Сведения о версии

- Используется `opendicom_sirius_database` (пользовательский образ базы данных на основе официального MongoDB).
- Система восстановления базы данных включена в образ `opendicom_sirius_database`.
- Система выполнения запланированных задач через cron.
- Система автоматического резервного копирования с политиками контроля хранения дампов и логов.
