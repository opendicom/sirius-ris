# Frontend 1.8.0 | Backend 1.8.0 | Database 8.2.6

## Сведения о версии

- Контроль маршрутов на фронтенде (Guards).
- Добавлен тип документа «Внутренний регистрационный номер».
- Статистика времени задержки (только для суперпользователя [Бета]).
- Множественный выбор для пользователей, составляющих отчёты.
- Поле поиска в формах.
- Управление сортировкой в заголовке компонентов списков.
- Форма запросов на запись.
- Компонент назначения отчётов.
- Альтернативная пересылка по электронной почте.
- Исправление: сортировка по `_id` по убыванию в `findOne` для отчётов.
- Список выставления счетов с описанием контраста.
- Добавлен индикатор загрузки (спиннер) в формы записей, выполнения и отчётов.
- Добавлен предварительный просмотр логотипа PDF-отчёта (формы организаций и филиалов).
- Логотипы `white_labeling` исключены из проекции по умолчанию.
