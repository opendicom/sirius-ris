# Frontend 1.0.0 | Backend 1.0.0

これは Sirius RIS の最初のリリースです。このバージョンは、さまざまな専門家とユーザーによって相当な期間にわたりテストされています。現在、このバージョンは本番環境で稼働しています。

## バージョン詳細

- 依頼（外部）の管理。
- 予約枠の管理。
- 予約および進行中の予約の管理。
- カレンダーの管理。
- 受付（MWL 対応）の管理。
- 検査の管理。
- レポートの管理（作成、編集、署名、認証、チェック）。
- 高度な検索モジュール。
- 統計モジュール。
- 関連するコンポーネントでの DICOM 画像の表示。
