# Frontend 1.0.0 | Backend 1.0.0

This is the first release of Sirius RIS. This version has been tested over a reasonable period by different specialists and users. This version is currently in productive mode.

## Version details

- Management of requests (external).
- Slot management.
- Appointment management and appointments drafts.
- Calendar management.
- Check-in management (with MWL).
- Study management.
- Report management (Creation, editing, signing, authentication and control).
- Advanced search module.
- Statistics module.
- Display of DICOM images in the components involved.
