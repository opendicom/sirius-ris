# Frontend 1.0.0 | Backend 1.0.0

Questa è la prima versione di Sirius RIS. Questa versione è stata testata per un periodo ragionevole da diversi specialisti e utenti. Attualmente questa versione è in produzione.

## Dettagli della versione

- Gestione delle richieste (esterne).
- Gestione dei turni.
- Gestione degli appuntamenti e degli appuntamenti in corso.
- Gestione del calendario.
- Gestione del check-in (con MWL).
- Gestione degli studi.
- Gestione dei referti (creazione, modifica, firma, autenticazione e controllo).
- Modulo di ricerca avanzata.
- Modulo di statistiche.
- Visualizzazione delle immagini DICOM nei componenti coinvolti.
