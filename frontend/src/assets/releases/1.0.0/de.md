# Frontend 1.0.0 | Backend 1.0.0

Dies ist die erste Version von Sirius RIS. Diese Version wurde über einen angemessenen Zeitraum von verschiedenen Fachleuten und Benutzern getestet. Diese Version befindet sich derzeit im Produktivbetrieb.

## Versionsdetails

- Verwaltung von (externen) Anfragen.
- Slot-Verwaltung.
- Verwaltung von Terminen und Terminentwürfen.
- Kalenderverwaltung.
- Check-in-Verwaltung (mit MWL).
- Studienverwaltung.
- Berichtsverwaltung (Erstellung, Bearbeitung, Unterschrift, Authentifizierung und Kontrolle).
- Modul für die erweiterte Suche.
- Statistikmodul.
- Anzeige von DICOM-Bildern in den beteiligten Komponenten.
