# Frontend 1.0.0 | Backend 1.0.0

Esta es la primera versión de Sirius RIS. Esta versión fue probada durante un período razonable por distintos especialistas y usuarios. Actualmente esta versión se encuentra en modo productivo.

## Detalles de la versión

- Gestión de solicitudes (externas).
- Gestión de turnos.
- Gestión de citas y de citas en curso.
- Gestión del calendario.
- Gestión de check-in (con MWL).
- Gestión de estudios.
- Gestión de informes (creación, edición, firma, autenticación y control).
- Módulo de búsqueda avanzada.
- Módulo de estadística.
- Visualización de imágenes DICOM en los componentes involucrados.
