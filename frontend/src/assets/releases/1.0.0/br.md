# Frontend 1.0.0 | Backend 1.0.0

Esta é a primeira versão do Sirius RIS. Esta versão foi testada por um período razoável por diferentes especialistas e usuários. Atualmente, esta versão está em modo de produção.

## Detalhes da versão

- Gerenciamento de requisições (externas).
- Gerenciamento de horários.
- Gerenciamento de agendamentos e rascunhos de agendamento.
- Gerenciamento do calendário.
- Gerenciamento de check-in (com MWL).
- Gerenciamento de estudos.
- Gerenciamento de laudos (criação, edição, assinatura, autenticação e controle).
- Módulo de pesquisa avançada.
- Módulo de estatísticas.
- Exibição de imagens DICOM nos componentes envolvidos.
