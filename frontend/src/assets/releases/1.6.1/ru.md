# Frontend 1.6.1 | Backend 1.6.1 | Database 8.2.6

## Сведения о версии

- Сжатие дампов базы данных в скрипте резервного копирования.
- Добавлен настраиваемый парсер документов.
- Изменена процедура получения IP-адреса клиента.
- Исправлена ошибка некорректного изменения состояния запроса на запись при создании записи.

**Важное примечание:** В этом выпуске для каждого типа документа в каждой стране можно ввести регулярное выражение, чтобы поле документа автоматически разбирало это значение.
