# Frontend 1.6.1 | Backend 1.6.1 | Database 8.2.6

## Detalles de la versión

- Compresión de los volcados (dumps) de la base de datos en el script de respaldo.
- Se agrega un analizador de documentos configurable.
- Cambio en el procedimiento para obtener la IP del cliente.
- Corrección de error en el cambio incorrecto del estado de flujo de la solicitud de cita al crear una cita.

**Nota importante:** En esta versión es posible ingresar una expresión regular para cada tipo de documento de cada país, de modo que el campo de documento analice automáticamente ese dato.
