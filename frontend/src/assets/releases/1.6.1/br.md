# Frontend 1.6.1 | Backend 1.6.1 | Database 8.2.6

## Detalhes da versão

- Compactação dos dumps do banco de dados no script de backup.
- Adiciona um analisador de documentos configurável.
- Alteração do procedimento para obter o IP do cliente.
- Correção de erro na alteração incorreta do estado de fluxo da requisição de agendamento ao criar um agendamento.

**Nota importante:** Nesta versão é possível informar uma expressão regular para cada tipo de documento de cada país, de modo que o campo de documento analise automaticamente esse dado.
