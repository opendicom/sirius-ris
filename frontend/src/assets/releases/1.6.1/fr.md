# Frontend 1.6.1 | Backend 1.6.1 | Database 8.2.6

## Détails de la version

- Compression des dumps de la base de données dans un script de sauvegarde.
- Ajout d'un analyseur de documents configurable.
- Modification de la procédure d'obtention de l'IP du client.
- Correction d'un bug de changement incorrect de l'état de flux de la demande de rendez-vous lors de la création d'un rendez-vous.

**Remarque importante :** Dans cette version, il est possible de saisir une expression régulière pour chaque type de document de chaque pays afin que le champ du document analyse automatiquement cette donnée.
