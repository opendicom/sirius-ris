# Frontend 1.5.0 | Backend 1.5.1 | Database 8.2.3

## Сведения о версии

- Полная интернационализация (i18n).
- Добавлен сервис тем для пользовательского интерфейса.
- Рефакторинг логики назначения пользователя, составляющего отчёт, для повышения читаемости и обеспечения проверки обязательных полей перед установкой этого пользователя.
- Исправление и унификация версионирования, а также исправление CVE-2025-14847 (MongoBleed).
- Обзор CVE: `ip` — неправильная классификация SSRF в `isPublic` (относится только к дереву разработки и не влияет на продуктивную сборку [в `package.json` добавлен override для принудительного использования последней версии]).
- Предупреждения о DoS для `multer` устранены для [CVE-2024-52080, CVE-2024-52081, CVE-2024-52082] в текущей версии; кроме того, добавлены ограничения размера файлов и middleware для предотвращения сбоев сервера из-за ошибок `multer` [Backend].
- Исправлена ошибка `upload_maxsize` [Frontend].
- Исправление ошибки: «Error during query MongoDB.» возникала при попытке создать отделения и процедуры.

**Важное примечание:** В этом выпуске реализована полная интернационализация системы.
