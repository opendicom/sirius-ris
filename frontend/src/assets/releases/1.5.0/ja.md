# Frontend 1.5.0 | Backend 1.5.1 | Database 8.2.3

## バージョン詳細

- 完全な国際化（i18n）。
- ユーザーインターフェース用のテーマサービスを追加しました。
- 報告者の割り当てロジックをリファクタリングし、可読性を向上させるとともに、報告者を設定する前に必須項目が検証されるようにしました。
- バージョン管理を修正・統一し、CVE-2025-14847（MongoBleed）に対処しました。
- CVE レビュー：`ip` — `isPublic` における SSRF の不適切な分類（開発ツリーにのみ適用され、本番ビルドには影響しません [最新バージョンを強制するため、`package.json` に override を追加しました]）。
- `multer` の DoS アラートを [CVE-2024-52080、CVE-2024-52081、CVE-2024-52082] について現行バージョンで解決しました。さらに、`multer` のエラーによるサーバーのクラッシュを防ぐため、ファイルサイズ制限とミドルウェアを追加しました [Backend]。
- `upload_maxsize` のエラーを修正しました [Frontend]。
- バグ修正：サービスや手技を作成しようとすると「Error during query MongoDB.」が発生する問題を修正しました。

**重要な注意：** このリリースでは、システム全体の国際化が導入されています。
